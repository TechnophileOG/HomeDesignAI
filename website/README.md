# KatalogitAI Landing Page

Modern, conversion-optimized landing page for KatalogitAI — AI-powered product photography for Indian online sellers.

## 🎯 Design Philosophy

**Target Audience:** Indian retail shop owners, D2C brands, and small business sellers
**Psychology:** Trust, results, simplicity — not tech jargon
**Colors:** Warm orange (#FF6B35) for action, teal for trust, cream backgrounds for warmth

## ✨ Key Features

### 1. Preloader Animation (1.5s)
- Camera icon "snapping" a photo
- Products in background
- Flash effect with "SNAP!" text
- Loads page + first video chunks

### 2. Hero Section
- **Left:** Rotating typing animation with honest value propositions
- Brand name appears after each phrase
- 4 key benefit points with checkmarks
- Dual CTA buttons (Start free + Call Now)
- **Right:** Before/after demo panel (flat-lay photo → 8 AI poses)
- Fully responsive grid layout

### 3. Comparison Section
- Side-by-side: Traditional vs KatalogitAI
- Step-by-step process comparison
- Clear cost breakdown
- "Popular" ribbon on KatalogitAI card

### 4. Results Section
- **Left:** Honest 4-step pipeline walkthrough (flat-lay → 8 poses → review → export)
- **Right:** Value card — real product facts (8 poses/product, 3 credits/shoot, from ₹15, private storage, 10 free credits)

### 5. Brand Carousel
- Platform logos (Amazon, Flipkart, Meesho, etc.)
- Subtle hover effects

### 6. Pricing Section
- 3 credit packs matching the real wallet: ₹249/50, ₹499/120, ₹999/300
- Clear feature lists
- 10 free credits to start

### 7. Contact Section
- Orange gradient background
- White form card
- Platform dropdown
- Direct contact buttons (Call + WhatsApp)

### 8. Footer
- Company info + trust badges
- Link columns
- Copyright
